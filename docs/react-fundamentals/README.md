# React fundamentals

These notes cover the building blocks of React function components:

- [JSX basics](jsx.md) — describing UI with JSX expressions and elements.
- [Function components](components.md) — defining, composing, exporting,
  importing, and rendering components.
- [Props](props.md) — passing data and callbacks, setting defaults, and
  designing reusable component APIs.
- [State with `useState`](use-state.md) — state values, setter functions,
  destructuring, and re-renders.

For JavaScript and React terms used across these topics, see the
[React terminology glossary](../terminology.md).

## React function components: learning checklist

Use this checklist to track topics to explore in depth in future conversations.
Each item starts unchecked; check it off as you work through the topic.

- [x] **JSX and component basics** — defining, exporting, importing, and rendering function components.
- [x] **Props** — passing data and callbacks, default values, and keeping components reusable.
- [x] **State** — using `useState`, updating state immutably, and understanding when updates trigger a re-render.
- [ ] **Events** — handling user interactions and passing event handlers between components.
- [ ] **Conditional rendering** — showing different UI based on props or state.
- [ ] **Lists and keys** — rendering collections and choosing stable keys.
- [ ] **Component composition** — building UIs from smaller components and using `children`.
- [ ] **Sharing state** — lifting state up and deciding where state should live.
- [ ] **Hooks** — understanding the Rules of Hooks and common Hooks such as `useState`, `useEffect`, `useContext`, and `useRef`.
- [ ] **Effects** — managing external synchronization, dependencies, and cleanup—and knowing when an effect isn’t needed.
- [ ] **Custom Hooks** — extracting and reusing stateful logic.
- [ ] **Forms** — controlled inputs, form submission, and validation.
- [ ] **Context** — sharing values across a component tree without passing props through every level.
- [ ] **Refs** — interacting with DOM elements or retaining values that don’t need to trigger a re-render.
- [ ] **Performance basics** — understanding re-renders and when memoization tools like `memo`, `useMemo`, or `useCallback` are actually useful.
- [ ] **Testing and accessibility** — checking rendered behavior and ensuring components work for different users and input methods.
